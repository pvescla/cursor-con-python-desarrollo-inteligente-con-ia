# Cursor con Python: desarrollo inteligente con IA

Starter workspace for Python development with Cursor and AI.

This repository currently holds project scaffolding only. Application code can be added under `src/`.

## Setup

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

`requirements.txt` can be added when the first Python dependencies are chosen.

## Status

The local Cursor installer (`.exe`) is intentionally not tracked in git.
